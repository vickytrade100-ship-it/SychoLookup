# 📱 Sycho Lookup

A modern Android app to search SIM & CNIC records using the Sycho Database API.

## Features
- 🔍 Mobile number & CNIC lookup
- 📋 Beautiful result cards with all data
- 🕘 Local search history (Room DB)
- 🌙 Dark mode support
- ⚡ Fast & clean Material 3 UI

## Tech Stack
- **Kotlin** + **Jetpack Compose**
- **MVVM** Architecture
- **Hilt** Dependency Injection
- **Retrofit** for API calls
- **Room** for local history

## API
Base URL: `https://sychosimdatabase.vercel.app/api/`
Developer: @Sychox2006

## Setup
1. Clone the repo
2. Open in Android Studio (Hedgehog or newer)
3. Sync Gradle
4. Run on device/emulator (API 26+)

## Build APK
`Build → Generate Signed Bundle / APK → APK → Release`
